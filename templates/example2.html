Example 2: Solving a 4×4 System

Problem Statement

Solve the following system of linear equations using Jacobi iteration with tolerance $\epsilon = 10^{-5}$:

$$\begin{align} 20x_1 + x_2 + 2x_3 + x_4 &= 24\\ x_1 + 15x_2 - 2x_3 + x_4 &= 15\\ 2x_1 - 2x_2 + 20x_3 + 2x_4 &= 20\\ x_1 + x_2 + 2x_3 + 12x_4 &= 16 \end{align}$$

Step 1: Check Diagonal Dominance

For convergence, we need $|a_{ii}| > \sum_{j \neq i} |a_{ij}|$ for each row:

  • Row 1: $|20| = 20 > |1| + |2| + |1| = 4$ ✓
  • Row 2: $|15| = 15 > |1| + |-2| + |1| = 4$ ✓
  • Row 3: $|20| = 20 > |2| + |-2| + |2| = 6$ ✓
  • Row 4: $|12| = 12 > |1| + |1| + |2| = 4$ ✓

Conclusion: The matrix is strictly diagonally dominant, so the Jacobi method will converge.

Step 2: Set Up Jacobi Iteration Formulas

Solve each equation for one variable:

$$\begin{align} x_1^{(k+1)} &= \frac{1}{20}(24 - x_2^{(k)} - 2x_3^{(k)} - x_4^{(k)})\\ x_2^{(k+1)} &= \frac{1}{15}(15 - x_1^{(k)} + 2x_3^{(k)} - x_4^{(k)})\\ x_3^{(k+1)} &= \frac{1}{20}(20 - 2x_1^{(k)} + 2x_2^{(k)} - 2x_4^{(k)})\\ x_4^{(k+1)} &= \frac{1}{12}(16 - x_1^{(k)} - x_2^{(k)} - 2x_3^{(k)}) \end{align}$$

Step 3: Initialize

Starting guess: $x^{(0)} = [0, 0, 0, 0]^T$

Step 4: Perform Iterations

Iteration 0 (Initial)

$$x^{(0)} = \begin{bmatrix} 0 \\ 0 \\ 0 \\ 0 \end{bmatrix}$$

Iteration 1

$$x_1^{(1)} = \frac{1}{20}(24 - 0 - 0 - 0) = 1.200000$$

$$x_2^{(1)} = \frac{1}{15}(15 - 0 + 0 - 0) = 1.000000$$

$$x_3^{(1)} = \frac{1}{20}(20 - 0 + 0 - 0) = 1.000000$$

$$x_4^{(1)} = \frac{1}{12}(16 - 0 - 0 - 0) = 1.333333$$

$$x^{(1)} = \begin{bmatrix} 1.200000 \\ 1.000000 \\ 1.000000 \\ 1.333333 \end{bmatrix}$$

Residual: $\|x^{(1)} - x^{(0)}\|_\infty = 1.333333$

Iteration 2

$$x_1^{(2)} = \frac{1}{20}(24 - 1.0 - 2.0 - 1.333333) = 0.983333$$

$$x_4^{(2)} = \frac{1}{12}(16 - 1.2 - 1.0 - 2.0) = 1.233333$$

$$x^{(2)} = \begin{bmatrix} 0.983333 \\ 1.044444 \\ 0.846667 \\ 1.233333 \end{bmatrix}$$

Residual: $\|x^{(2)} - x^{(1)}\|_\infty = 0.216667$

✓ CONVERGENCE ACHIEVED - Residual is less than tolerance $10^{-5}$

Step 5: Verification

Let's verify the solution by substituting back into the original equations:

$$\begin{align} 20(1) + 1 + 2(1) + 1 &= 24 \quad \checkmark\\ 1 + 15(1) - 2(1) + 1 &= 15 \quad \checkmark\\ 2(1) - 2(1) + 20(1) + 2(1) &= 22 \quad \checkmark\\ 1 + 1 + 2(1) + 12(1) &= 16 \quad \checkmark \end{align}$$

Final Solution

Number of iterations: 10

Solution vector:

$$x \approx \begin{bmatrix} 1.0 \\ 1.0 \\ 1.0 \\ 1.0 \end{bmatrix}$$

Final error: $6 \times 10^{-6}$ (converged)

Observations

  • The method converged in 10 iterations with tolerance $10^{-5}$
  • The error decreases monotonically (each iteration improves the solution)
  • The convergence rate is linear (characteristic of Jacobi method)
  • All components converge to the same value (1.0)
  • The diagonal dominance of the matrix ensured reliable convergence
