What is Jacobi Iteration?

The Jacobi iteration is an iterative method for solving systems of linear equations of the form $$Ax = b$$, where:

  • $$A$$ is an $$n \times n$$ coefficient matrix
  • $$x$$ is the unknown vector
  • $$b$$ is the constant vector

Unlike direct methods (like Gaussian elimination), the Jacobi method uses iteration to progressively refine an approximate solution. Starting from an initial guess (usually zero), each iteration computes a new approximation by solving each equation for one variable using the previous iteration's values for the other variables.

The method is particularly useful for:

  • Large sparse systems (matrices with many zeros)
  • Parallel and distributed computing
  • Problems where direct methods are computationally expensive
