Example 1: Solving a 3×3 System

Problem Statement

Solve the following system of linear equations using Jacobi iteration with tolerance $\epsilon = 10^{-6}$:

$$\begin{align} 10x_1 + x_2 + x_3 &= 12\\ x_1 + 10x_2 + x_3 &= 12\\ x_1 + x_2 + 10x_3 &= 12 \end{align}$$

Step 1: Check Diagonal Dominance

For convergence, we need $|a_{ii}| > \sum_{j \neq i} |a_{ij}|$ for each row:

  • Row 1: $|10| = 10 > |1| + |1| = 2$ ✓
  • Row 2: $|10| = 10 > |1| + |1| = 2$ ✓
  • Row 3: $|10| = 10 > |1| + |1| = 2$ ✓

Conclusion: The matrix is strictly diagonally dominant, so the Jacobi method will converge.

Step 2: Set Up Jacobi Iteration Formulas

Solve each equation for one variable:

$$\begin{align} x_1^{(k+1)} &= \frac{1}{10}(12 - x_2^{(k)} - x_3^{(k)})\\ x_2^{(k+1)} &= \frac{1}{10}(12 - x_1^{(k)} - x_3^{(k)})\\ x_3^{(k+1)} &= \frac{1}{10}(12 - x_1^{(k)} - x_2^{(k)}) \end{align}$$

Step 3: Initialize

Starting guess: $x^{(0)} = [0, 0, 0]^T$
